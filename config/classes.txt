# Vocabulário do YOLO-World.
#
# Formato:   rótulo no catálogo: prompt em inglês[, outro prompt, ...]
#            (sem ":" o próprio rótulo é usado como prompt)
#
# - Os prompts vão para o modelo; prefira inglês, termos concretos e visuais.
# - Vários prompts para o mesmo rótulo aumentam a chance de detecção.
# - Listas menores tendem a dar menos confusão entre classes: deixe só o que
#   você realmente quer catalogar.
# - Depois de editar, reinicie o servidor.
